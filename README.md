Dual-Axis Solar Tracker ☀️
A dual-axis solar tracking system developed using two stepper motors and TB6600 drivers to control the azimuth and elevation of a solar panel.
Features
•	Dual-axis stepper motor control
•	TB6600 stepper motor drivers
•	Embedded microcontroller programming
•	Firmware developed in C and Assembly
•	Circuit and control simulation in Proteus
•	Firmware development using MPLAB
